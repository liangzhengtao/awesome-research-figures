# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-08-17

### Added

#### Python Plotting Skills
- **matplotlib-publication**: Publication-quality matplotlib figures with IEEE/Nature/Science templates
- **seaborn-statistical**: Statistical visualization (heatmaps, pair plots, violin+strip)
- **network-graphs**: Network visualization (citation, collaboration, knowledge graphs)
- **ML-figures**: ML result visualization (confusion matrices, ROC curves, training curves)

#### R Plotting Skills
- **ggplot2-publication**: Publication-quality ggplot2 with multi-panel, survival, forest plots
- **bioinformatics-plots**: Bioinformatics visualization (volcano plots, heatmaps, Sankey diagrams)

#### LaTeX Plotting Skills
- **pgfplots-charts**: Data visualization with PGFPlots (line, bar, scatter, 3D surface)
- **tikz-diagrams**: Technical diagrams with TikZ (CNN architecture, transformers, flowcharts)

#### Diagram Skills
- **drawio-diagrams**: Technical diagrams with draw.io (architecture, ER, flowcharts)
- **excalidraw-sketches**: Hand-drawn style diagrams for presentations

#### Formatting Skills
- **journal-specs**: Complete journal figure specifications (IEEE, Nature, Science, Elsevier, Springer, ACM)
- **figure-composition**: Multi-panel figure composition (2×2 grid, 1+2 layout, timeline)

# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

This repository contains documentation and code templates only. There are no runtime services, APIs, or compiled binaries.

If you find a security concern:

1. **Code template issues**: If a code template has a dependency with a known vulnerability, open an Issue with the details.
2. **Malicious content**: If you find content that could harm users' systems, email the maintainer directly.

## Scope

This project does **not**:
- Run any servers or services
- Process user data
- Execute code automatically
- Install dependencies without user action

The code templates are provided as-is for users to copy and adapt. Users are responsible for reviewing and running code in their own environments.

## Proven Patterns for Users

- Always review code templates before running them
- Use virtual environments for Python dependencies
- Keep your R packages and LaTeX distributions updated
- Do not run code templates with elevated privileges
